# BeamLab — 材料力学・梁計算Webアプリ

機械設計者向けの、ブラウザだけで動作する梁の強度・剛性検討ツールです。複数荷重を重ね合わせ、反力、せん断力、曲げモーメント、曲げ応力、たわみ角、たわみ、安全率を計算・可視化します。

## 技術構成

- React + TypeScript + Vite
- Vitest
- SVG（梁模式図、SFD、BMD、たわみ曲線）
- localStorage（ケース保存）
- 外部API・サーバー不要

## 起動・ビルド

```bash
npm install
npm run dev
npm test
npm run build
```

PowerShellでスクリプト実行が制限されている環境では `npm.cmd run dev` のように実行してください。

## 計算理論

内部単位はN–mm–MPaです。Euler–Bernoulli梁要素による剛性法を使用し、各節点に鉛直変位と回転の2自由度を持たせて全体剛性方程式 `K u = F` を解きます。分布荷重は線形分布の一貫荷重ベクトルとして要素へ組み込みます。支点、集中荷重、集中モーメント、分布荷重の開始・終了位置は解析節点として明示的に追加されます。

全体剛性行列は密行列ではなく半帯幅3の対称帯行列として保持し、対角スケーリング付きCholesky分解で解きます。これによりブラウザ上でメモリを抑えながら多数の節点を扱えます。小規模な1次元梁解析に過剰な依存を追加しないため、外部数値計算ライブラリは使用していません。

- 上向き荷重・変位: 正
- 反時計回り集中モーメント・回転: 正
- 曲げ応力: `σ = M / Z`
- 安全率: `降伏応力（耐力）/ 最大曲げ応力`
- FEM実効要素数: 高速100 / 標準250 / 高精度500（重要位置は別途必ず節点化）

## 注意事項

材料値は一般的な参考値です。熱処理、板厚、規格、加工状態で変化するため、最終設計では使用材料の規格値を確認してください。

本計算は、断面・材料が梁全長で一定である線形弾性・小変形Euler–Bernoulli梁の簡易計算です。せん断変形、座屈、局部応力、応力集中、接触、塑性変形、疲労、溶接部、動荷重、横倒れ座屈等は別途検討してください。設計判断は有資格技術者が検証してください。
