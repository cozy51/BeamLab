# BeamLab — 材料力学・梁計算Webアプリ

機械設計者向けの、ブラウザだけで動作する梁の強度・剛性検討ツールです。複数荷重を重ね合わせ、反力、せん断力、曲げモーメント、曲げ応力、たわみ角、たわみ、安全率を計算・可視化します。

## 技術構成

- React + TypeScript + Vite
- Vitest
- SVG（梁模式図、SFD、BMD、たわみ曲線）
- localStorage（ケース保存）
- 外部API・サーバー不要

## 起動・ビルド

```bash
npm install
npm run dev
npm test
npm run build
```

PowerShellでスクリプト実行が制限されている環境では `npm.cmd run dev` のように実行してください。

## 計算理論

内部単位はN–mm–MPaです。Euler–Bernoulli梁理論 `EI d²v/dx² = M(x)` を用います。実荷重と未知反力から断面力を構成し、全体の力・モーメント釣合い、および各支持位置の変位・回転境界条件を連立して反力を求めます。曲率を数値積分して回転・たわみを計算します。荷重境界は解析点へ明示的に追加されます。

- 上向き荷重・変位: 正
- 反時計回り集中モーメント・回転: 正
- 曲げ応力: `σ = M / Z`
- 安全率: `降伏応力（耐力）/ 最大曲げ応力`
- 標準分割数: 1000（200 / 1000 / 5000を選択可能）

## 注意事項

材料値は一般的な参考値です。熱処理、板厚、規格、加工状態で変化するため、最終設計では使用材料の規格値を確認してください。

本計算は、断面・材料が梁全長で一定である線形弾性・小変形Euler–Bernoulli梁の簡易計算です。せん断変形、座屈、局部応力、応力集中、接触、塑性変形、疲労、溶接部、動荷重、横倒れ座屈等は別途検討してください。設計判断は有資格技術者が検証してください。
